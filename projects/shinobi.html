The revenge of Shinobi

❮ Previous ❯ Next

Back in 2024, I recreated the first stage of The Revenge of Shinobi for a school project. We were given a custom C++ game engine and tasked with recreating a 2D game. This was my first major game development project, and it gave me the opportunity to learn how to build a game from the ground up. The game still has a few mistakes, but it was a great learning experience and an important step in my development as a programmer. Looking back, I've improved a lot since then, which makes this project a nice way to see how far I've come.
