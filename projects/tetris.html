Tetris

Last year, I was tasked with recreating a retro game using C++ with Lua scripting bindings. I decided to recreate tetris one of the most iconic games of all time. During this project, my main goal was to use as little C++ as possible and implement most of the game's logic in Lua. This allowed me to explore how scripting languages can be integrated into a C++ game engine and how they can be used to manage gameplay systems. Additionally, I used CMake to configure and generate the project, giving me more experience with build systems and project configuration in C++. This project helped me deepen my understanding of C++ and Lua integration, while also improving my ability to structure a game project and separate engine functionality from gameplay logic.
