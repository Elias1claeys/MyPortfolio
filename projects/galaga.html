SplaShroom

❮ Previous ❯ Next

This project started with a very empty game engine. There was no sound implemention, no input system, no component system and many more missing features. My task was to implement these features myself using the design patterns and techniques I learned in class, and then use that engine to create a fully functional game. I had to remake Galaga. It is an arcade game from the 1980s in wich you control a space ship and fight waves of attacking aliens. A challenge I had while making this game was implementing the weird movement curves that the aliens made. I eventually solved this by using bezier curves, which allowed me to create smooth and varied flight paths. The enemie also goes trought a lot of different stages when he attacks. It all depends on the type of enemy and wich attack the game randomly decided to use. I used CMake to manage the project generation and build process. Overall this project deepens my understanding of game engine architecture and improved my C++ programming skills.
